# music.vladislove.online

Страница артиста Chernyshev: релизы, продюсирование, соцсети. Статическая: `index.html` + обложки в `covers/`.

## Как добавить релиз
1. Положи обложку в `covers/` (квадрат, лучше 1000×1000, jpg).
2. Скопируй в `index.html` блок `<a class="rel" …>` в разделе «Мои релизы» (или `<a class="track" …>` в «Продюсировании»), поменяй ссылку, обложку, название и дату.
3. Обнови счётчик «N релизов» и при необходимости карточку «Скоро выйдет» в шапке.
4. `git add . && git commit -m "Новый релиз" && git push` — сайт обновится через минуту.
